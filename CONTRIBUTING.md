# Contributing

Help keep this collection useful by submitting resource additions, corrections, and maintenance updates through pull requests.

## Suggest a resource

1. Choose the relevant section in [README.md](README.md): **Language model projects** or **Aviation tools**.
2. Link to the original project's repository or official documentation.
3. Add a short description of what the project does and who would use it.
4. Check for an existing entry before adding a new one.

Use the existing format:

```markdown
### [Project name](https://github.com/owner/project)

One or two sentences describing the project's purpose and intended use.
```

## Include evidence in your pull request

- Link to the project's license. Distinguish code, model-weight, and dataset licenses when they differ.
- Link to setup instructions or a working usage example.
- Note whether the project is active, archived, or a historical research reference, using its own repository or release history as evidence.
- Explain why it belongs in this collection and whether it replaces an existing entry.

Free access and an open-source license are different. Describe restrictions accurately, and attribute performance or capability claims to the original project's documentation.

## Correct an existing entry

For a moved project, link to the new canonical location. For an inaccurate description, cite the source supporting the correction in the pull request. Explain removals so maintainers can distinguish broken links from intentionally retained historical projects.

## Check before submitting

- Confirm that each new or changed link opens the intended resource.
- Preview the Markdown and check headings and section links.
- Preserve unrelated entries, credits, and existing license files.

A documentation-only change does not require a model download or a flight simulator installation.
